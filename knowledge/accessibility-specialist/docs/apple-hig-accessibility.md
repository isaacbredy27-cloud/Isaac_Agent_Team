# Apple HIG — accessibility numbers

Source: https://developer.apple.com/design/human-interface-guidelines/accessibility (read 2026-11-25)

| Platform | Default control size | Minimum control size |
|---|---|---|
| iOS, iPadOS | 44×44 pt | 28×28 pt |
| macOS | 28×28 pt | 20×20 pt |

| Text size | Weight | Minimum contrast |
|---|---|---|
| Up to 17 pt | All | 4.5:1 |
| 18 pt | All | 3:1 |
| All | Bold | 3:1 |

- "Ideally, give people the option to enlarge text by at least 200 percent."
- Reduce Motion: "reduce automatic and repetitive animations, including zooming, scaling, and peripheral motion."
