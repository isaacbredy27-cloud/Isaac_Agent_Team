# Apple HIG — Color

Source: https://developer.apple.com/design/human-interface-guidelines/color (read 2026-11-25)

- "Avoid using the same color to mean different things."
- "Make sure all your app's colors work well in light, dark, and increased contrast contexts." Supply light and dark variants and an increased-contrast option for each; "Even if your app ships in a single appearance mode, provide both light and dark colors to support Liquid Glass adaptivity."
- "Avoid relying solely on color to differentiate between objects, indicate interactivity, or communicate essential information." Use text labels or glyph shapes too.
- "Avoid hard-coding system color values"; don't redefine semantic colors (e.g. separator as text).
- Liquid Glass color: glass "has no inherent color" and takes color from content behind it. "Apply color sparingly." "To emphasize primary actions, apply color to the background rather than to symbols or text." "Refrain from adding color to the background of multiple controls."
- Small elements (tab bars, toolbars) flip between light and dark appearance with content; larger elements (sidebars) appear more opaque.
- Colorful backgrounds → prefer a monochromatic tab bar/toolbar.
