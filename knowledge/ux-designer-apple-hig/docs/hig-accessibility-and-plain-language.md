# HIG accessibility basics and plain language

Sources (read 2026-11-25): https://developer.apple.com/design/human-interface-guidelines/accessibility · https://www.plainlanguage.gov/guidelines/

- iOS controls: default 44×44 pt, minimum 28×28 pt. Text should scale to 200%.
- Contrast: up to 17 pt → 4.5:1; 18 pt or bold → 3:1.
- Reduce Motion: cut automatic and repetitive animation.
- Plain language (plainlanguage.gov): write for your audience, use short sentences and paragraphs, active voice, common words, "you"; put the most important information first.
