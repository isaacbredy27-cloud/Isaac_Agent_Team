# Finance Career Paths

## Use when
- Mapping titles to seniority
- Setting transfer weights
- Writing future actions for weak matches

## Inputs → Outputs
- Inputs: Titles, career histories, target roles.
- Outputs: Ladder position, transfer weight, next-step advice.

## Purpose
Understand where a candidate is and where they can go next.

## Ladders (typical years)
Analyst (1–3) → Senior/Staff Analyst (3–7) → Manager (6–10+) → Director (10+).

## Roles → signature skills → credential that helps
| Role | Skills | Credential |
|---|---|---|
| FP&A Analyst | driver models, forecasting, Adaptive/Anaplan/Hyperion | CMA |
| Corporate Finance | DCF, valuation, board decks | CFA |
| Treasury | cash forecasting, TMS, banking | CTP |
| Credit Analyst | spreading, ratio analysis, credit memos | — |
| Risk Analyst | SQL/Python, statistics, CECL/Basel | FRM |
| Investment Analyst | valuation, Bloomberg/FactSet | CFA |
| Revenue Analyst (hospitality) | forecasting, pricing systems | — |
| Defense program finance | EVM, EAC/ETC, Deltek Costpoint | clearance |
| Wealth Associate | client service, planning | SIE, Series 7/66, CFP |
| Finance Manager | leadership, planning cycles | CPA/MBA |

## Transfer weights (feed skill-taxonomy)
Accountant→FP&A 0.8 · Big-4 audit→Corporate finance 0.8 · Bank credit→Corporate credit 0.8 · BI analyst→FP&A 0.6 · Military finance→Defense program finance 0.7 · Hotel revenue manager→Revenue/FP&A 0.7 · Project controls→Program financial analyst 0.6.

## Future actions for Red matches
Name the smallest next step: one tool course (e.g., Adaptive Planning), one credential level (CFA L1, SIE), a bridge role, or a quantified project bullet.

## Common mistakes
- Treating "preferred CPA" as required.
- Recommending expensive credentials when a tool skill closes the gap.

## Best practices
- Base advice on posting evidence
- Prefer the smallest next step
- Treat 'preferred' credentials as optional

## Checklist
- [ ] Title mapped to family and level
- [ ] Transfer weight documented
- [ ] Advice names one concrete action
